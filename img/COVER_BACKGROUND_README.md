# Cover Background Image

To add a beautiful cover page with background image to the book:

1. Place your background image in this directory with one of these names:
   - `cover-background.pdf` (recommended for best quality)
   - `cover-background.png`
   - `cover-background.jpg`

2. The image should be:
   - High resolution (at least 2480x3508 pixels for A4 at 300 DPI)
   - Landscape or portrait orientation (will be scaled to fit)
   - Beautiful and professional design

3. The cover page will automatically display:
   - Title: "Math for AI/ML"
   - Subtitle: "A comprehensive mathematics textbook for AI/ML"
   - Author: "MockSphere.com"

4. The text will have a shadow effect for better visibility on the background.

Example: You can use one of the background PDFs from:
`git-repo/pandoc-latex-template/examples/page-background/backgrounds/`
